# 프로젝트 인계

작성 상태: 미작성 양식입니다. 아래 항목을 실제 근거로 채운 뒤 이 문장을 수정합니다. 실제로 실행하지 않은 명령과 관찰을 수행 결과로 쓰지 않습니다.

## 목적과 현재 상태

해결할 문제와 현재 구현된 동작을 설명합니다. 완료한 요구 ID와 실패·미확인 요구 ID를 구분합니다.

## 실행과 재현

필요한 환경, 작업 디렉터리, 시작·종료 명령과 예제 입력을 적습니다. 실제 출력과 기대값을 연결합니다. 예시 명령과 실행한 명령을 구분합니다.

## 핵심 처리 경로

입력 하나가 파싱, 검증, 처리와 출력으로 이어지는 파일과 함수를 연결합니다. 다른 담당자가 그 경로를 따라갈 수 있게 설명합니다.

## 선택과 비용

중요한 선택, 실제 대안, 선택 이유와 감수한 한계를 적습니다. 사용자 승인과 AI 제안을 구분하고 관련 근거를 연결합니다.

## 검증 근거

실제 명령, 검사 ID, 로그 위치와 현재 판본에서의 결과를 적습니다. 자동 검사와 사용자 직접 확인을 구분합니다. 변경 후 오래된 근거는 현재 통과로 쓰지 않습니다.

## 남은 문제와 다음 작업

재현 조건, 영향, 아직 확인하지 않은 동작과 다음 조치를 적습니다. 범위나 동작 변경에 사용자 승인이 필요하면 표시합니다.

## 사용자의 확인

사용자가 실제로 선택하거나 확인했다고 답한 내용만 적습니다. 답변이 없으면 확인 대기로 남깁니다. AI의 실행과 설명을 사용자의 직접 수행이나 이해로 바꾸지 않습니다.
