# 최상위 하네스 가드레일

모든 작업 전에 [.harness-kit/GUARDRAILS.md](.harness-kit/GUARDRAILS.md)를 읽고 적용합니다. 시험 전 범용 도구의 공개 준비와 시험 중 구현을 구분합니다. 시험 중에는 Git push와 문제·작업 자료의 외부 전송을 하지 않습니다. 해당 시험에서 금지한 AI 연결과 자동 UI 조작을 사용하지 않습니다. AI 사용 금지 서술형 단계에서는 작업을 중단합니다.

현재 작업의 공식 규정과 과제 원문을 먼저 확인합니다. [HARNESS.md](HARNESS.md)를 읽고 미해결 질문과 계획을 정리합니다. 사용자의 명시적인 계획 승인 뒤 구현합니다. 하위 에이전트와 외부 스킬에도 같은 제한을 전달합니다.

이 문서는 실행 지침입니다. OS의 네트워크 차단이나 플랫폼 감독 기능을 대신하지 않습니다. 공식 제출과 사용자 직접 관찰을 자동 완료로 기록하지 않습니다.
