# 업무 담당자 답변 기록

작성 상태: 미작성 양식입니다. 실제 질문과 답변만 기록합니다. 대화가 없으면 이 문서를 답변 기록으로 사용하지 않습니다. 접근 정보와 불필요한 개인정보는 적지 않습니다.

## 대화와 출처

| 항목 | 실제 기록 |
| --- | --- |
| 프로젝트 원문과 판본 | `[파일 또는 위치, 확인한 시각]` |
| 질문 채널과 발화자 | `[실제 채널, 사람 또는 대화형 AI 역할, 권한 확인 상태]` |
| 대화 기록 위치 | `[프로젝트 안의 파일 또는 접근 가능한 기록 식별 위치]` |
| 질문 시각 | `[실제 시각 또는 기록 내 순서]` |
| 보낸 질문 원문 | `[실제 질문]` |
| 받은 답변 원문 | `[해당 판단을 지지하는 짧은 실제 인용]` |
| 요약 | `[인용과 분리한 자신의 해석]` |

## 요구 판단

| 항목 | 실제 기록 |
| --- | --- |
| 상태 | `[원문 명시 / 담당자 진술 / 확정 / 가정 / 충돌 / 미확인]` |
| 결정 주체와 확인 근거 | `[결정 권한이 있는 사람 또는 미확인]` |
| 영향을 받는 처리 | `[입력, 출력, 제외, 우선순위, 예외 중 실제 영향]` |
| 충돌하는 근거 | `[두 출처와 서로 다른 내용 또는 없음]` |
| 다음 질문과 담당자 | `[해결에 필요한 질문과 답할 사람 또는 없음]` |

## 구현과 수용 기준 연결

| 항목 | 실제 기록 |
| --- | --- |
| 요구 ID | `[R1 또는 아직 부여하지 않음]` |
| 정상 사례와 기대 결과 | `[작은 입력과 관찰 가능한 출력]` |
| 예외 사례와 기대 결과 | `[경계 또는 실패 입력과 관찰 가능한 결과]` |
| 수용 기준 | `[누가 무엇을 확인하면 수용하는지]` |
| 검사 ID와 방법 | `[C1, 명령과 예상 결과 또는 수동 확인 항목]` |
| 실제 실행 결과 | `[실행 시각, 로그 위치와 결과 또는 미실행]` |
| 관련 구현 | `[파일과 함수 또는 미구현]` |

답변은 원문과 해석을 나눠 적습니다. 한 답변에서 여러 요구가 나오면 요구별로 위 기록을 복제하고 각 요구의 근거 문장을 지정합니다. 답변이나 원문이 바뀌면 이전 결정과 검사 근거의 판본을 다시 확인합니다.
