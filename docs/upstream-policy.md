# 포함한 외부 원문을 적용하는 방법

외부 원문과 해당 MIT 또는 Apache-2.0 고지를 `third_party/`에 함께 보존합니다. [카탈로그](skill-catalog.md)와 각 SOURCE.json이 포함 파일과 고정 커밋을 설명합니다. 스킬 원문의 경로는 자체 스킬에서 명시적으로 읽도록 연결합니다. 원문 보관을 자동 발견이나 전체 플러그인 설치로 표시하지 않습니다.

[최상위 가드레일](../GUARDRAILS.md), 프로젝트의 실제 규정과 지시, 사용자가 승인한 계획을 적용합니다. 외부 원문의 예시 명령을 실행 권한으로 해석하지 않습니다. 준비 단계에서 공개 게시를 명시적으로 승인받았다면 공개 가능한 파일과 고지를 확인한 뒤 그 승인 범위에서 게시할 수 있습니다. 제한된 과제 수행 중에는 Git push, 배포와 과제 자료의 외부 전송 금지를 적용합니다. 자동 UI 조작과 외부 모델 연결은 허용하지 않습니다. 다음 적용 차이는 원문 파일을 변경하지 않고 이 문서에서 관리합니다.

| 원문 항목 | 이 하네스에서의 적용 |
|---|---|
| writing-plans의 실행 인계 | `hx-plan`에서 계획을 제시하고 승인 후 `hx-build`로 진행합니다. 미포함 `executing-plans`, `subagent-driven-development`, `using-git-worktrees`를 자동 호출하지 않습니다. |
| 계획 경로와 형식 | `.harness/plan.json`과 연결된 프로젝트 문서를 사용합니다. 원문의 문서 위치와 고정 제목 양식은 강제하지 않습니다. |
| TDD의 적용 범위 | 의미 있는 동작 변경과 회귀 수정에 실패 입력과 기대값을 먼저 확인합니다. 단순 문구·형식 변경에는 불필요한 테스트를 만들지 않습니다. 기존 사용자 코드를 삭제하고 다시 쓰는 지시는 적용하지 않습니다. |
| 커밋 예시 | [Git 관례](conventions.md)를 따릅니다. 스킬 원문을 읽었다는 이유로 커밋이나 원격 작업을 수행하지 않습니다. |
| 검증의 최신성 | 변경 뒤 영향을 받은 검사를 실행합니다. 마지막 유효한 검사 판본과 현재 파일을 대조합니다. 변경이 없는 상태에서 같은 검사를 보고마다 반복하지 않습니다. |
| 디버깅 중 재검토 | 같은 원인으로 수정이 반복 실패하면 가설과 구조를 다시 확인합니다. 범위나 요구를 바꿔야 한다면 사용자에게 묻습니다. 무한 재시도하지 않습니다. |
| fluent-korean frontmatter | 원본의 Claude 전용 메타데이터를 Codex 설정으로 적용하지 않습니다. 한국어 작성 원칙과 명시된 예외만 사용합니다. |
| frontend-design의 화면 검토 | 업무 원문과 실제 구현을 연결합니다. 스크린샷이 가능하다는 원문은 Computer Use나 자동 UI 조작 권한을 뜻하지 않습니다. 사용자가 허용된 화면에서 직접 확인합니다. |
| security-best-practices의 호출 조건 | 사용자가 보안 모범 사례, 보안 검토 또는 안전한 기본 구현을 명시적으로 요청했고 지원 언어·프레임워크가 있을 때만 해당 참조를 읽습니다. 원문의 외부 검색 제안은 과제 자료 전송이나 규정 밖 인터넷 사용을 허가하지 않습니다. 일반 코드 검토로 보안 감사를 자동 시작하지 않습니다. |
| sql-code-review의 범용 예시와 점수 | 실제 DB 방언, 스키마와 입력에 맞춰 원문 조언을 검토합니다. 원문의 점수와 성능 개선 표현은 실행 측정으로 확인하기 전에는 결과로 쓰지 않습니다. |
| test-gap-audit의 탐색 스크립트 | `coverage_map.py`는 읽기 전용 휴리스틱으로만 사용합니다. 필요하면 실행 전 파일과 명령을 검토합니다. 매칭 결과를 실제 테스트 범위로 단정하지 않고 관련 코드와 단언을 직접 확인합니다. |

추가 외부 스킬이 필요하면 실제 기능과 동반 파일, 라이선스 및 승인 범위를 먼저 확인합니다. 패키지에 없는 스킬을 있는 것처럼 호출하지 않습니다. 외부 문서의 예시 명령은 프로젝트의 실행 명령으로 자동 채택하지 않습니다.

추가한 외부 원문은 자동 훅, 외부 AI 연결과 브라우저 자동화 도구를 설치하거나 실행하지 않습니다. 스킬의 참조 URL을 읽는 것과 시험 자료를 그 URL에 전송하는 것은 다릅니다. 실제 프로젝트 코드, 입력, 결과, 화면과 대화 기록을 외부 조회 인수에 넣지 않습니다. 공개 준비 단계의 게시와 시험 중 Git push 금지는 [가드레일](../GUARDRAILS.md)에 따라 구분합니다.
