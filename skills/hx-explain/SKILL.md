# 구현 설명과 이해 확인

작업이 열려 있을 때 brief, 원문, 코드와 실제 로그를 함께 읽습니다. brief는 기록을 모은 보기이며 자동 코드 분석이나 사용자 이해 인증이 아닙니다. 작업이 closed라면 추가 명령과 설명을 멈춥니다.

핵심 입력 하나가 어떤 함수와 데이터 처리를 거쳐 결과가 되는지 설명합니다. 실제 선택의 대안, 이유와 비용을 현재 검사 결과에 연결합니다. AI가 제안한 내용과 사용자가 직접 결정한 내용을 구분합니다. 아직 받지 않은 사용자 답변을 만들지 않습니다.

사용자에게 현재 코드의 입력·경계값·실패 처리와 확인 범위를 자신의 말로 설명할 수 있는 질문을 제시합니다. AI가 설명했다는 사실로 사용자 이해를 완료 처리하지 않습니다. 문서 작성에는 hx-document를 적용하고 handoff.md에 현재 상태와 근거 위치를 연결합니다.
