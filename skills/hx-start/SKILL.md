# 프로젝트 시작과 재개

먼저 작업 공간의 `.harness-kit/GUARDRAILS.md`와 원문, 적용 지침, 기존 파일과 실행 명령을 읽습니다. 요구가 불명확하거나 업무 담당자 대화가 제공되면 `.agents/skills/hx-discover/SKILL.md`를 읽고 답변을 확인합니다. 질문 채널이 없으면 답변을 만들어 내지 않고 사용자에게 질문합니다. 설치가 필요하면 `python3 <toolkit>/hx.py --root <project> install`을 사용합니다. 기존 상태가 없을 때만 `init`을 실행하고, 있으면 `status`와 `plan`을 읽습니다. `doctor`는 환경 조회입니다.

`.harness/contract.json`에 원문 인용, 작은 입력의 기대 결과, 예정 구현 경로와 검사 ID를 연결합니다. 아직 없는 구현 파일은 계획 단계에서 만들었다고 주장하지 않습니다. 원문 요구가 빠졌는지는 직접 대조합니다.

반드시 `.agents/skills/hx-plan/SKILL.md`로 진행합니다. 계획과 질문이 해결되지 않거나 명시 승인이 없으면 구현을 시작하지 않습니다. 읽기 전용 데이터 조사와 계획 작성은 계속할 수 있습니다. 자동 스킬 발견이 확인되지 않으면 파일을 직접 읽습니다.
